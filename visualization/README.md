# Variant Hierarchy Visualization

This directory contains the D3.js hierarchy browser merged from
`D:\github\variant_hierarchy`. The original project is left untouched; this copy is
adapted to read the CSV files generated by the Python hierarchy pipeline in this
repository.

## Data Inputs

The page reads:

- `../data/graph/node_with_info.csv`
- `../data/graph/edge.csv`

Generate or refresh those files with:

```bash
python -c "from hierarchy.hierarchy_class import get_neo4j; get_neo4j(with_info=True)"
```

`node_with_info.csv` must include:

- `entity:ID`
- `name`
- `:LABEL`
- `variant_info`

`variant_info` uses this repository's normalized fields:
`display_name`, `location.gene`, `location.exon`, `alteration.type`,
`variant_class`, and `source`.

## Run Locally

Serve the repository root so the relative data paths resolve correctly:

```bash
python -m http.server 8000
```

Open:

```text
http://localhost:8000/visualization/
```

## Features

- Search by gene and render its descendant hierarchy.
- Search by variant node and inspect ancestor paths plus descendants.
- Switch between gene hierarchy and node hierarchy modes.
- Expand/collapse hierarchy branches.
- Reveal hidden siblings when a parent has many children.
- Pan, zoom, and reset the tree viewport.
- Inspect normalized variant metadata in tooltips.
